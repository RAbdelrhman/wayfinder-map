How this canvas works

Each frame is one option. Compare them here, click one (or ▶) to open it full size, then say which direction you want, or which parts of each. Named rounds keep earlier options visible; notes can show what each option came from.

P [ ]
Pick a page, previous / next page
1–9
Open an item full size
← →
Previous / next item while presenting
Esc
Back to the canvas
T
Light / dark inside every frame
N
Show or hide the option notes and feedback controls
+ − 0
Zoom in, out, fit (or Ctrl + wheel). Drag empty space to pan.

For each option, choose Keep, Change, or Combine, add a detail, then select and copy the generated feedback into the ticket or next-round request.
